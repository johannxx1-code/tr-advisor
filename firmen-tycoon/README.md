# Firmen-Tycoon

Wirtschaftssimulation im Browser (Vite + TypeScript + Three.js). Konzept und Regeln: siehe `CLAUDE.md`.

```bash
cd firmen-tycoon
npm install
npm run dev        # http://localhost:5173 – im WLAN über die angezeigte „Network“-Adresse
```

Tests: `npm test`

Steuerung: Ziehen = verschieben, Mausrad/Pinch = zoomen, Leertaste = Pause, 1/2/3 = Geschwindigkeit, Esc = Panel schließen.
